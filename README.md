## ✨ Overview

e-Nirikshan is a frontend project focused on presenting public development-work information through a structured, accessible monitoring interface.

The goal is to make project information easier to navigate and help users identify records that may need further review.

## 🚀 Features

- 📊 **Monitoring Dashboard** — Explore available project indicators.
- 📑 **Reports & Analytics** — Review project reports and relevant information.
- 🚨 **Alerts & Monitoring** — Highlight items that may require attention.
- 🔎 **Project Exploration** — Navigate project information through the interface.
- 🔗 **Backend Integration** — Connect the frontend to its configured API service.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

```bash
git clone https://github.com/codemasteryash/mplad-guard-frontend.git
cd mplad-guard-frontend
npm install
npm run dev
```

Open the local URL printed in your terminal.

### Production Build

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```

## 🔌 Backend Configuration
